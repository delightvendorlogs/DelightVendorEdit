Email and Telegram delivery

Admin alerts are sent automatically when important admin notifications are created. Email goes to delightvendorlogs@gmail.com. Telegram goes to the chat configured by TELEGRAM_CHAT_ID.

Add these exact names in Supabase → Project Settings → Edge Functions → Secrets:

The shared alert webhook secret and VAPID public key are read from Supabase Vault. They are not entered here.

Delivery checklist

Email requires RESEND_API_KEY. Telegram requires TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID. Email is delivered to delightvendorlogs@gmail.com. Resend may require a verified sender domain; the default onboarding sender is suitable only for permitted test sending.
